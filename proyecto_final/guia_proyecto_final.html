1. ¿Qué estamos haciendo y por qué?

Una financiera quiere anticiparse a la competencia e identificar qué clientes tienen más probabilidad de aceptar la renovación de su préstamo. Para eso cuenta con 2 meses de historia de llamadas del call center (FLAG_VENTA = 1 si el cliente renovó) más información financiera y demográfica de cada cliente.

En el notebook Caso Renovación de Préstamo.ipynb ya se hizo el análisis exploratorio, la limpieza (capping, log1p, imputación), el One-Hot Encoding, un clustering K-Means y se probaron estrategias de balanceo y modelos. La conclusión fue usar Random Forest sobre datos con UnderSampling, y se hizo un GridSearchCV manual.

En este proyecto llevamos ese notebook al flujo MLOps del Tema 6: scripts .py reproducibles, búsqueda de hiperparámetros con GridSearchCV y RandomizedSearchCV, registro de cada experimento en MLflow, comparación programática de runs y promoción del ganador al Model Registry.

■ El problema: solo el 3.99 % de los clientes renueva. Con un desbalance así la accuracy engaña (predecir siempre «no renueva» da 96 %). Por eso balanceamos el train, optimizamos el F1 de la clase positiva y registramos también Recall, Precision y ROC-AUC, que son las métricas que el notebook considera relevantes para el negocio.
2. ¿Qué lograrás al final?
  • Convertir el preprocesamiento del notebook en un script reproducible con semilla fija (random_state=42).
  • Comparar Originales / UnderSampling / OverSampling / SMOTE con una línea base.
  • Aplicar GridSearchCV (búsqueda exhaustiva) con Stratified K-Fold sobre un RandomForest.
  • Aplicar RandomizedSearchCV (búsqueda aleatoria eficiente).
  • Registrar cada experimento en MLflow con parámetros y métricas comparables.
  • Comparar todos los runs con mlflow.search_runs() y elegir el mejor por F1.
  • Registrar el modelo ganador en el MLflow Model Registry (Staging).

"""
Secciones 1-7 — Pipeline base sin tuning (Caso Renovación de Préstamo).

Reproduce el notebook "Caso Renovación de Préstamo.ipynb":
carga el dataset, renombra columnas, aplica capping + log1p, imputa nulos,
codifica las categóricas (One-Hot), agrega el cluster K-Means (K=3),
hace el split 70/30, compara Originales / Under / Over / SMOTE con un
DecisionTree y entrena un RandomForest base sobre Undersampling.
Exporta base_data.pkl para que los scripts de tuning lo reutilicen.

Ejecutar: python pipeline/01_base_pipeline.py
"""
import pickle
import numpy as np
import pandas as pd
from pathlib import Path

from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier
from sklearn.cluster import KMeans
from sklearn.metrics import (
    classification_report, accuracy_score, roc_auc_score,
    f1_score, recall_score, precision_score,
)
from imblearn.over_sampling import SMOTE

RANDOM_STATE = 42
np.random.seed(RANDOM_STATE)

# ── Sección 1: Cargar dataset ─────────────────────────────────────────────────
DATA_PATH = Path("data/Renovacion_prestamo.csv")
if not DATA_PATH.exists():
    raise FileNotFoundError(
        f"No se encontró {DATA_PATH}. Copia 'Dataset Renovacion_prestamo.csv' "
        "a data/Renovacion_prestamo.csv"
    )

df = pd.read_csv(DATA_PATH, sep=";")
print(f"Dataset cargado: {df.shape}")

# Renombrar columnas para un mejor entendimiento (igual que el notebook)
df.rename(columns={
    "LINEA_RENOVADO": "Linea_Renovado",
    "PLAZO_RENOVADO": "Plazo_Renovado",
    "USO_LINEA_TOTAL_TC_T2": "Uso_Linea",
    "USO_TRIM_LINEA_BBVA": "Uso_TrimLinea",
    "NR_ENTIDADES_TOTAL_T2": "Nro_Entidades",
    "DIFF_NRO_ENTIDA_TOTALES_T2_T12": "Dif_Entidades",
    "SDO_CONSUMO_T2": "Saldo_Consumo",
    "RESENCIA_OFERTA_PLD_RENOVADO": "Meses_oferta",
    "Ahorro_Sldo_Bco_T1": "Ahorro",
    "PConsumo_Sldo_Bco_T1": "Prestamo_vigente",
    "SDO_BCO_tot_sm_pasivo_Bco_6M": "Promed_6Mdeuda",
    "FLAG_LIMA_PROVINCIA": "Flag_LimProv",
    "CUBRIR_DEUDA_CONSUMO_SF_RENOVA_PLD": "Deuda_Cubierta%",
}, inplace=True)

# ── Sección 2: Exploración ────────────────────────────────────────────────────
TARGET = "FLAG_VENTA"
print(f"\nShape       : {df.shape}")
print(f"Columnas    : {list(df.columns)}")
print("\nDistribución del target:")
print(df[TARGET].value_counts())
print(df[TARGET].value_counts(normalize=True).round(4))
print(f"\nDuplicados  : {df.duplicated().sum()}")
print("\nNulos por columna (solo > 0):")
nulos = df.isna().sum()
print(nulos[nulos > 0].sort_values(ascending=False))

# ── Sección 3: Capping + transformación logarítmica ──────────────────────────
# Saldos negativos (deudas) -> 0 para poder aplicar log1p
for col in ["Ahorro", "Prestamo_vigente", "Promed_6Mdeuda"]:
    df[col] = np.maximum(0, df[col])

COLS_LOG = [
    "Uso_Linea", "Uso_TrimLinea", "Saldo_Consumo", "SUELDO_ESTIMADO", "ANTIGUEDAD_MES",
    "Linea_Renovado", "Ahorro", "Prestamo_vigente", "Promed_6Mdeuda", "Deuda_Cubierta%",
]
for col in COLS_LOG:
    df[f"{col}_LOG"] = np.log1p(df[col])

# ── Sección 4: Imputación de nulos ───────────────────────────────────────────
# > 15 % nulos: sampling aleatorio uniforme en [media - std, media + std]
for col in ["Uso_TrimLinea_LOG", "Uso_Linea_LOG", "Meses_oferta"]:
    media, std = df[col].mean(), df[col].std()
    nulos_col = df[col].isnull()
    df.loc[nulos_col, col] = np.random.uniform(
        max(0, media - std), media + std, nulos_col.sum()
    )

# < 15 % nulos: mediana
for col in ["Saldo_Consumo_LOG", "SUELDO_ESTIMADO_LOG", "ANTIGUEDAD_MES_LOG", "EDAD"]:
    df[col] = df[col].fillna(df[col].median())

# Categóricas: moda
CATEGORICAS = ["REGION", "SEXO", "EST_CIVIL"]
for col in CATEGORICAS:
    df[col] = df[col].fillna(df[col].mode()[0])

# ── Sección 5: One-Hot Encoding + Cluster K-Means ────────────────────────────
df_encoded = pd.get_dummies(df, columns=CATEGORICAS, drop_first=False, dtype=int)

FEATURES_CLUSTER = ["Uso_TrimLinea_LOG", "Prestamo_vigente_LOG", "Uso_Linea_LOG"]
kmeans = KMeans(n_clusters=3, init="k-means++", random_state=RANDOM_STATE, n_init=10)
df_encoded["Cluster"] = kmeans.fit_predict(df_encoded[FEATURES_CLUSTER])
print("\nDistribución de clientes por cluster:")
print(df_encoded["Cluster"].value_counts().sort_index().to_dict())

# Quitar las columnas originales que ya tienen versión _LOG
df_final = df_encoded.drop(columns=COLS_LOG)
print(f"\nDataset final: {df_final.shape}")

# ── Sección 6: Split 70/30 ────────────────────────────────────────────────────
# MES y CLIENTE no son variables predictivas
X = df_final.drop(columns=[TARGET, "MES", "CLIENTE"])
y = df_final[TARGET].astype(int)

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.30, random_state=RANDOM_STATE, stratify=y
)
print(f"\nTrain: {X_train.shape} | Test: {X_test.shape}")
print(f"Train target dist: {y_train.value_counts().to_dict()}")
print(f"Test  target dist: {y_test.value_counts().to_dict()}")

# ── Sección 6b: UnderSampling, OverSampling y SMOTE ──────────────────────────
n_minority   = int(y_train.sum())
n_majority   = int((y_train == 0).sum())
idx_majority = y_train[y_train == 0].index
idx_minority = y_train[y_train == 1].index

rng = np.random.RandomState(RANDOM_STATE)

# UnderSampling — reducir la clase mayoritaria al tamaño de la minoritaria
idx_under = rng.choice(idx_majority, size=n_minority, replace=False)
X_under = pd.concat([X_train.loc[idx_under], X_train.loc[idx_minority]])
y_under = pd.concat([y_train.loc[idx_under], y_train.loc[idx_minority]])

# OverSampling — duplicar la clase minoritaria al tamaño de la mayoritaria
idx_over = rng.choice(idx_minority, size=n_majority - n_minority, replace=True)
X_over = pd.concat([X_train, X_train.loc[idx_over]])
y_over = pd.concat([y_train, y_train.loc[idx_over]])

# SMOTE — generar ejemplos sintéticos de la clase minoritaria
smote = SMOTE(k_neighbors=5, sampling_strategy="minority", random_state=RANDOM_STATE)
X_smote, y_smote = smote.fit_resample(X_train, y_train)

print(f"\nUnderSampling: {X_under.shape} | dist: {y_under.value_counts().to_dict()}")
print(f"OverSampling : {X_over.shape} | dist: {y_over.value_counts().to_dict()}")
print(f"SMOTE        : {X_smote.shape} | dist: {pd.Series(y_smote).value_counts().to_dict()}")


def evaluar(modelo, nombre):
    """Métricas de la clase positiva (renueva = 1) sobre el test set."""
    y_pred  = modelo.predict(X_test)
    y_proba = modelo.predict_proba(X_test)[:, 1]
    res = {
        "accuracy":  round(accuracy_score(y_test, y_pred), 4),
        "f1":        round(f1_score(y_test, y_pred), 4),
        "recall":    round(recall_score(y_test, y_pred), 4),
        "precision": round(precision_score(y_test, y_pred, zero_division=0), 4),
        "roc_auc":   round(roc_auc_score(y_test, y_proba), 4),
    }
    print(f"\n[{nombre}]")
    for k, v in res.items():
        print(f"  {k:<9}: {v:.4f}")
    return res


# ── Sección 7: DecisionTree base (sin tuning) por estrategia de balanceo ─────
print("\n" + "=" * 50)
print("SECCIÓN 7 — DecisionTree base (sin tuning)")
print("=" * 50)

resultados_base = {}
for nombre, X_bal, y_bal in [
    ("Originales",    X_train, y_train),
    ("UnderSampling", X_under, y_under),
    ("OverSampling",  X_over,  y_over),
    ("SMOTE",         X_smote, y_smote),
]:
    dt = DecisionTreeClassifier(random_state=RANDOM_STATE)
    dt.fit(X_bal, y_bal)
    resultados_base[nombre] = evaluar(dt, f"DecisionTree — {nombre}")

# El notebook eligió Random Forest + UnderSampling: es la LÍNEA BASE del tuning
print("\n=== REPORTE COMPLETO — RandomForest + UnderSampling (línea base para tuning) ===")
rf_base = RandomForestClassifier(random_state=RANDOM_STATE)
rf_base.fit(X_under, y_under)
resultados_base["RandomForest-Under"] = evaluar(rf_base, "RandomForest — UnderSampling")
print(classification_report(y_test, rf_base.predict(X_test), digits=3))

print("\n=== RESUMEN LÍNEA BASE ===")
print(pd.DataFrame(resultados_base).T.to_string())

# ── Exportar datos para scripts de tuning ────────────────────────────────────
Path("src").mkdir(exist_ok=True)
with open("src/base_data.pkl", "wb") as f:
    pickle.dump((X_under, y_under, X_test, y_test), f)

print("\n✓ Datos exportados a src/base_data.pkl (train = UnderSampling)")
print("  Siguiente paso: python pipeline/02_gridsearch_mlflow.py")
Observación técnica — OverSampling corregido: en el notebook, la celda de OverSampling hacía df_class_0.sample(count_class_1, replace=True): muestreaba la clase mayoritaria al tamaño de la minoritaria, o sea, otro UnderSampling (por eso daba 2444/2444). El script duplica la clase minoritaria hasta igualar a la mayoritaria, que es lo que la técnica pretende.
Observación técnica — fuga de información (se mantiene igual al notebook): la imputación (media, std, mediana, moda) y el K-Means se calculan sobre el dataset completo antes del split, así que el test «ve» estadísticas del train. Se conserva para que los resultados sean comparables con el notebook; en producción estos pasos se ajustan solo con el train (por ejemplo dentro de un Pipeline de scikit-learn).
Observación técnica — ¿por qué UnderSampling + RandomForest y no SMOTE + DecisionTree como en la Unidad 06? Porque es la conclusión del propio caso: en el notebook el DecisionTree con SMOTE tuvo recall 0.074 (casi no detecta renovaciones) y el Random Forest con UnderSampling fue el elegido. GridSearchCV + MLflow (Run 1)
pipeline/02_gridsearch_mlflow.py

Búsqueda exhaustiva sobre 48 combinaciones × 5 folds = 240 entrenamientos del RandomForestClassifier (amplía la grilla del notebook con n_estimators=10 y max_depth=4, los valores del «Random Forest tuneado» manual). El mejor estimador se evalúa en test y se registra en MLflow como Run 1.

python — pipeline/02_gridsearch_mlflow.py
"""
Sección 8 — GridSearchCV + MLflow (Run 1).

Búsqueda exhaustiva de hiperparámetros del RandomForest sobre los datos
balanceados con UnderSampling (igual que el notebook).
4 x 4 x 3 = 48 combinaciones x 5 folds = 240 entrenamientos.
Registra el mejor en MLflow como Run 1.

Ejecutar: python pipeline/02_gridsearch_mlflow.py
Prerrequisito: src/base_data.pkl (generado por 01_base_pipeline.py)
"""
import pickle
import mlflow
import mlflow.sklearn
from pathlib import Path

from sklearn.model_selection import GridSearchCV, StratifiedKFold
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import (
    accuracy_score, f1_score, recall_score,
    precision_score, roc_auc_score, classification_report,
)

import os
os.environ["MLFLOW_ALLOW_FILE_STORE"] = "true"

RANDOM_STATE = 42

# ── Cargar datos de la sección base ──────────────────────────────────────────
BASE_PKL = Path("src/base_data.pkl")
if not BASE_PKL.exists():
    raise FileNotFoundError(
        "No se encontró src/base_data.pkl. "
        "Ejecuta primero: python pipeline/01_base_pipeline.py"
    )

with open(BASE_PKL, "rb") as f:
    X_train_u, y_train_u, X_test, y_test = pickle.load(f)

print(f"Datos cargados — Train: {X_train_u.shape} | Test: {X_test.shape}")

# ── 8.1 Configurar MLflow ─────────────────────────────────────────────────────
# Usar ruta absoluta correcta — evita el bug de PermissionError en Codespaces
MLFLOW_DIR   = Path("mlruns").resolve()           # ruta absoluta real
TRACKING_URI = MLFLOW_DIR.as_uri()                # file:///workspaces/.../mlruns
EXPERIMENT   = "renovacion-prestamo-tuning"

MLFLOW_DIR.mkdir(parents=True, exist_ok=True)     # crear si no existe

mlflow.set_tracking_uri(TRACKING_URI)
mlflow.set_experiment(EXPERIMENT)
print(f"MLflow tracking URI : {TRACKING_URI}")
print(f"MLflow experiment   : {EXPERIMENT}")

# ── 8.2 Definir espacio de búsqueda y ejecutar GridSearchCV ──────────────────
param_grid = {
    "n_estimators":     [10, 50, 100, 150],   # 4 opciones
    "max_depth":        [4, 10, 20, None],    # 4 opciones
    "min_samples_leaf": [1, 2, 4],            # 3 opciones
    "class_weight":     ["balanced"],         # 1 opción (desbalance residual)
}
# 4 x 4 x 3 x 1 = 48 combinaciones x 5 folds = 240 entrenamientos

skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=RANDOM_STATE)

gs = GridSearchCV(
    estimator          = RandomForestClassifier(random_state=RANDOM_STATE),
    param_grid         = param_grid,
    cv                 = skf,
    scoring            = "f1",
    n_jobs             = -1,
    verbose            = 1,
    return_train_score = True,
)

print("\nEjecutando GridSearchCV (48 combinaciones x 5 folds)...")
gs.fit(X_train_u, y_train_u)

print(f"\nMejores parámetros : {gs.best_params_}")
print(f"Mejor F1 CV        : {gs.best_score_:.4f}")

# ── 8.3 Registrar en MLflow ───────────────────────────────────────────────────
n_combinaciones = len(gs.cv_results_["params"])

with mlflow.start_run(run_name="GridSearch-RandomForest") as run:
    # Parámetros del mejor estimador
    mlflow.log_params(gs.best_params_)
    mlflow.log_param("metodo_busqueda",  "GridSearchCV")
    mlflow.log_param("n_combinaciones",  n_combinaciones)
    mlflow.log_param("tecnica_balanceo", "UnderSampling")
    mlflow.log_param("n_folds",          5)
    mlflow.log_param("random_state",     RANDOM_STATE)

    # Evaluar en test set (clase positiva = renueva el préstamo)
    y_pred_gs  = gs.best_estimator_.predict(X_test)
    y_proba_gs = gs.best_estimator_.predict_proba(X_test)[:, 1]
    mlflow.log_metrics({
        "accuracy":   round(accuracy_score(y_test,                    y_pred_gs), 4),
        "f1":         round(f1_score(y_test,                          y_pred_gs), 4),
        "recall":     round(recall_score(y_test,                      y_pred_gs), 4),
        "precision":  round(precision_score(y_test, y_pred_gs, zero_division=0), 4),
        "roc_auc":    round(roc_auc_score(y_test,                    y_proba_gs), 4),

Cada árbol del bosque contiene un objeto sklearn.tree._tree.Tree, que skops no acepta por defecto: sin el parámetro, log_model() falla con «Untrusted types found in the file: ['sklearn.tree._tree.Tree']».     "max_depth":         randint(2, 25),
    "min_samples_split": randint(2, 50),

    "criterion":         ["gini", "entropy"],
    "class_weight":      ["balanced"],

    scoring             = "f1",
    random_state        = RANDOM_STATE,
    n_jobs              = -1,
    verbose             = 1,

    """Ejecuta un script y retorna True si tuvo éxito."""

        capture_output=False,   # muestra output en tiempo real
    )

    if resultado.returncode == 0:
        log.info("<<< OK: %s (%.2f s)", nombre, duracion)
        return True
    else:
        log.error("XXX FALLO: %s (%.2f s)", nombre, duracion)

7. ¿Qué aprendiste en este proyecto?
Del notebook al pipeline
Las celdas de exploración se convirtieron en un script determinista: misma semilla, mismas transformaciones y un único split reutilizado por todos los experimentos.
Desbalance de clases
Con 3.99 % de positivos, la accuracy no sirve para elegir. Se balancea solo el train y se evalúa con F1, Recall, Precision y ROC-AUC sobre un test con la distribución real.
Grid vs. Random sobre un RandomForest
Grid recorre todas las combinaciones de una grilla chica; Random explora un espacio más amplio (7 hiperparámetros) con menos entrenamientos.
MLflow tracking + Registry
Cada búsqueda es un run con parámetros, métricas y modelo. search_runs() elige el mejor y register_model() lo publica en Staging.
Lectura de negocio
El modelo detecta la mayoría de los clientes que renuevan (recall alto) pero con precision baja: de cada 100 clientes contactados pocos renuevan. Sirve para priorizar la campaña, no para decidir cliente por cliente.
